## Trace 验收覆盖

- Provider 成功：trace 与响应共享 `request_id`，记录候选 Skill、最终 Skill、Provider、`model_called` 和耗时。
- 全局 fallback：记录未超过阈值的候选、`provider=none` 和 `no_enabled_skill_above_threshold`。
- Provider 失败：记录 `provider_request_failed`，并区分“调用过模型”和规则降级。
- 隐私边界：完整消息、用户 ID、session 原值没有出现在序列化 trace 中；session 只生成 SHA-256 前 16 位摘要。
- 故障隔离：trace sink 抛异常时，聊天响应仍保持原有结构和 fallback debug 字段。
- 公开契约：现有聊天 API 测试继续通过，trace 不增加公开响应字段。
