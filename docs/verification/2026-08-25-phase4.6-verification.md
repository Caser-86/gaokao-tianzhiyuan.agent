## Objective

为会话、微信媒体事件、公众号 replay receipt 和 Agent trace 建立可解释的收集、脱敏、保留、清理与用户删除边界，不引入重型依赖或删除既有功能。

## Implementation evidence

- `GAOKAO_AGENT_CHAT_SESSION_RETENTION_DAYS` 和 `GAOKAO_AGENT_MEDIA_ANALYSIS_RETENTION_DAYS` 默认 30 天，写/查询路径和 API startup 会清理过期 SQLite 记录。
- `GAOKAO_AGENT_AGENT_TRACE_RETENTION_DAYS` 默认 7 天；trace 只通过现有结构化 logger 输出，不写数据库，生产由 journald/容器日志轮转执行保留期。
- [`data_retention.py`](../../apps/api/app/services/data_retention.py) 在同一事务中清理过期会话、消息、媒体事件和 replay receipt，并按删除数量返回结果。
- `DELETE /api/privacy/me` 只接受现有 HTTP-only cookie 或 Bearer session，按服务端 subject 删除该主体的会话、消息和媒体事件；不会删除其他用户，也不会返回被删内容。
- Agent trace 继续不记录消息原文、Prompt 原文、API key、openid 或原始 session id；媒体分析继续不保存图片二进制。
